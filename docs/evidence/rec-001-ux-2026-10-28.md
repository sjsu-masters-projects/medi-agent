- Recorded pending/approved/rejected source-review labels in the list and detail;
  absent status explicitly unavailable, with no approval inferred from uploader.
- Saved-locale explanation sections and visible AI attribution. Existing summaries
  of unknown language use the same presentation path rather than an English cache
  assumption. Sections render as plain text with semantic headings and short lists.
- Response validation, bounded retries, number/unit counts, negation and clear
  language-mismatch guards. No unverified fallback to cached source text.
- Stale document/locale/account/token responses rejected and requests aborted on
  cleanup. Only displayed, available explanation text enters speech or chat context.
- One sticky modal close control; retained Escape, focus return, source viewing,
  upload, chat and existing guarded deletion. Speech leaves content visible and
  stops when its context changes.
